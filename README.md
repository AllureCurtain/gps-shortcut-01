One excuse from a GPS, 120 characters, in its own voice after sending the driver down the wrong road:

> I never sent you into the lake — the map said there was a bridge, and I only follow the map, the same way you follow me.

The GPS denies everything, blames the map for a bridge that was never there, then turns the accusation back on the driver: it only follows the map, the same way the driver follows it. The laugh is in the blame-shuffle — each clause passes the fault one step further away from the speaker.

## Run it

```sh
node main.ts
```

It prints the line and writes it to `/output/entry.txt`.
